# NOTABENOID TOOL

## Описание

Программа для обновления базы текста на [Notabenoid.org](https://notabenoid.org).
<br>В основном используется при обновлении игр или программ — сравнивает старую и новую локализацию, автоматически применяет изменения на сайте.
<br>Экономит массу времени: не нужно вручную удалять, добавлять и редактировать каждую строку на Notabenoid.
<br>Все изменения применяются автоматически, с сохранением привязанных переводов.

## Возможности

* **Добавление/изменение/удаление строк** при сравнении двух файлов локализации (старого и нового).
  * Правильно обрабатывает удалённые строки и автоматически обновляет ID последующих, чтобы не было разрыва.
  * Для блоков «N старых строк → M новых» использует умное сопоставление (монотонное назначение по похожести) — переводы сохраняются даже если количество строк в блоке не совпадает.
* **Комментарии к новым строкам** — для удобства отслеживания обновлений.
* **Обновление ID строк** по запросу — убирает дыры в нумерации (например, после удалений).
* **Скачивание оригинала и перевода** с сайта — в `.txt` или `.json`.
* **Массовая замена** текста перевода — во всей книге или в одной главе. Целиком или частично.
* **Режим «Пробный прогон» (dry-run)** — на вкладках «Добавить оригинал» и «Заменить»: показывает план изменений, ничего не отправляя на сайт.
* **Поддержка HTML-переносов** — `\n` в JSON превращается в `<br>` на сайте.
* **Автоматическое скачивание оригинала с сайта** — не обязательно выбирать старый файл вручную.
* **CSRF и HTTPS** — токен обновляется автоматически, при протухании сессии запрос повторяется.

## Важно знать

> ⚠️ **Все книги на Notabenoid приватные.** Без логина и пароля программа не работает — даже в dry-run, потому что для сравнения нужно скачать HTML книги с сайта.

> ⚠️ **После обновления ID проверьте нумерацию на сайте!** «Добавить оригинал» и «Заменить» работают по порядковым номерам строк. Если нумерация сбилась — запустите «Обновить ID» ещё раз, откройте книгу в браузере и убедитесь, что строки идут `#1, #2, #3…` подряд.

## Вкладки программы

### Добавить оригинал
Сравнивает текущее состояние книги на сайте с новым файлом локализации и применяет изменения (добавить / изменить / удалить).

* Заполните логин, пароль и URL книги.
* Выберите «Новый файл оригинала» — это новое состояние книги.
* «Файл оригинала с сайта» можно не указывать — программа сама скачает текущее состояние с сайта.
* Комментарий (необязательно) — добавится к новым строкам.
* Включите «Сравнить файлы без замены» — покажет план без отправки на сайт.

### Обновить ID
Убирает дыры в нумерации строк (например, после удалений). Укажите номер строки, с которой начать — обычно `1`.

### Скачать текст
Сохраняет оригинал или перевод книги в файл `.txt` или `.json`.

* «Непереведённое» — только строки без перевода (для «Оригинал»).
* «Заменять пустые строки оригиналом» — если перевода нет, подставить текст оригинала.
* При скачивании перевода: если у фрагмента несколько вариантов, берётся лучший (с классом `best`). Если лучшего нет — первый по порядку.

### Заменить
Массовая замена текста перевода. Укажите:
* URL **главы** (`https://notabenoid.org/book/NNN/MMM`) — только в ней;
* или URL **книги** (`https://notabenoid.org/book/NNN`) — во всех главах книги.

Параметры:
* **«Только целые строки»** — заменять, только если перевод полностью совпадает с искомым текстом.
* **Без галки** — заменять вхождения подстроки внутри более длинных переводов (все вхождения).
* ⚠️ **Поиск регистрозависим:** `Hello` и `hello` — разные строки.
* ⚠️ **Ищется по тексту перевода, а не по CSS-классу.** Если у `<div>` есть `class="best"`, но текст `defddd`, программа при поиске `best` его не найдёт.

> 💡 Для запросов длиной 2+ символов программа автоматически использует серверный фильтр `?show=6&tt=…` — скачиваются только страницы с совпадениями. На больших книгах (десятки тысяч строк) это ускоряет работу в 100+ раз.

### Добавить перевод
Загрузка перевода из файла. Количество строк в файле должно **точно** совпадать с числом фрагментов на сайте (с галкой «Непереведённое» — только с числом непереведённых). Пустые строки файла пропускаются.

## Режим «Пробный прогон»

На вкладках «Добавить оригинал» и «Заменить» есть галка «Пробный прогон» (синхронизированы друг с другом). При включении:
* POST-запросы на изменение **не отправляются**;
* в лог пишется список планируемых действий (`would insert`, `would replace` и т.д.).

Используйте для проверки плана перед боевым прогоном.

## Форматы файлов

* **Кодировка: UTF-8.** В блокноте — «Сохранить как → UTF-8».
* **`.txt`** — читается построчно. Каждый перенос `\n` = отдельная строка. Пустые строки в середине файла сохраняются.
* **`.json`** — плоский список строк: `["строка 1", "строка 2", ...]`.
  * Перенос внутри строки пишется как `\n` (два символа: обратный слэш и `n`), на сайте станет `<br>`.
  * Реальный перенос внутри JSON-строки — невалидный JSON, но программа распарсит его мягко (с предупреждением в логе).

## Типичные проблемы

### Задача упала с ошибкой
На сайте состояние может быть частично изменено. **Очистите поле «Файл оригинала с сайта»** и перезапустите — программа перекачает актуальное состояние.

### Нумерация строк сбилась
1. Запустите «Обновить ID», `lineNumber = 1`.
2. Откройте книгу на сайте, проверьте что строки идут подряд `#1, #2, #3…`.
3. Не запускайте «Добавить оригинал» или «Заменить», пока ID не выровнены.

### Замена ничего не находит
* Проверьте регистр (`Hello` ≠ `hello`).
* Проверьте, что ищете по тексту, а не по CSS-классу.
* Попробуйте без галки «Только целые строки» — возможно, текст входит в состав более длинной строки.

### `Length mismatch` при добавлении перевода
Количество строк в файле не совпало с числом фрагментов на сайте. Скачайте оригинал с сайта (вкладка «Скачать текст») и сравните количество строк.
